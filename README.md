# Quadcopter Drone Control App Using Flutter – Version 1

The first version of a Flutter (Dart) mobile application for controlling a quadcopter drone.

## About the Project

This project is the initial version of a drone control app. It provides a basic mobile interface for sending control commands to a quadcopter.

The app is built with Flutter and Dart. Later improvements were made in Version 2.

- Flutter SDK

## Working Principle

1. The user opens the application on a mobile device.
2. The app connects to the drone's communication module.
3. Control inputs from the interface are converted into commands.
4. Commands are sent to the drone's flight controller.
5. The drone responds to the commands.

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/sakthi960/QUADCOPTER-DRONE-CONTROL-APP-FLUTTER-VERSION-1.git
```

2. Install the Flutter SDK.
3. Open the project in VS Code or Android Studio.
4. Install dependencies.

```bash
flutter pub get
```

5. Connect a device or start an emulator.
6. Run the application.

```bash
flutter run
```

**Note:** Refer to the actual implementation for the drone communication method, command format and hardware requirements.
